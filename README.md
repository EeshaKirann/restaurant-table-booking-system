# Restaurant Table Booking System

A **Python console application** that allows users to manage restaurant table reservations through a simple menu-driven interface.

## How it works

- Users can view the status of all restaurant tables.
- Available tables can be booked by entering the table number and customer name.
- Existing bookings can be cancelled.
- The application updates and displays the latest table availability.
- Runs continuously until the user chooses to exit.

## Concepts used

- **Functions** for creating tables, booking, cancellation, and displaying table status.
- **Modular Programming** by separating the project into multiple Python files.
- **Dictionary** to store table numbers and booking status.
- **Conditional Statements (`if`, `elif`, `else`)** for booking validation and menu selection.
- **Loops (`while`)** to keep the application running.
- **User Input Handling** using the `input()` function.

## How to Run

1. Install **Python 3**.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```

4. Choose one of the following options:
   - View Tables
   - Book Table
   - Cancel Booking
   - Exit
